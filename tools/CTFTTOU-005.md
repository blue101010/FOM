# CTFTTOU-005 — NTFS metadata analyzers

> **Tool ID:** `CTFTTOU-005`  
> **Related techniques/counters:** CTFTCTE-FOR-018

## Description

MFTECmd, analyzeMFT and The Sleuth Kit provide read-only examination of NTFS
metadata and image structure. CTFT records them as evidence tools; it does not
embed their commands or authorize access to any target.
