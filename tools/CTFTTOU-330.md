## Description

NetExec (formerly CrackMapExec) is a network execution tool designed for lateral movement, exploitation, and post-exploitation tasks. It supports a wide range of protocols including SMB, WinRM, SSH, RDP, LDAP, and more. Often used in CTFs for full pwn scenarios involving Active Directory and Windows networks.
