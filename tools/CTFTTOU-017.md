# CTFTTOU-017 — BloodHound / SharpHound

> **Tool ID:** `CTFTTOU-017`  
> **Related techniques/counters:** CTFTTE-FPN-011, CTFTCTE-FPN-011, CTFTTE-FPN-013, CTFTCTE-FPN-013, CTFTTE-FPN-018, CTFTCTE-FPN-018

## Description

Active Directory attack-path graphing. SharpHound is the native Windows collector and the reference for coverage; Python-based collectors (bloodhound-python, bloodhound-ce-python) and the built-in netexec collection produce smaller graphs and can hide paths such as GenericWrite or WriteDacl edges.
