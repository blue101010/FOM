# CTFTTOU-316 — commix

> **Tool ID:** `CTFTTOU-316`  
> **Related techniques/counters:** CTFTCTE-WEB-021, CTFTTE-WEB-021

## Description

Automated OS command injection detection and exploitation tool (classic, eval-based,
time-based and file-based techniques) for parameters, headers and cookies, with a
pseudo-terminal once a vector is confirmed. Use it after a reproducible manual signal, and
keep its payloads within the challenge scope.
