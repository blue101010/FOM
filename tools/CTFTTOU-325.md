# CTFTTOU-325 — Overpass Turbo

> **Tool ID:** `CTFTTOU-325`  
> **Related techniques/counters:** CTFTCTE-OSI-004, CTFTTE-OSI-004

## Description

Web IDE for the Overpass API over OpenStreetMap data. It queries features by tag and
spatial relation (e.g. every pharmacy within 50 m of a tram stop in a city, or a church
next to a river bridge) and maps the results, turning visual clues from a photo into a
short list of candidate locations.
