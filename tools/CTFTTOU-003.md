# CTFTTOU-003 — UPX Fixer

> **Tool ID:** `CTFTTOU-003`  
> **Related techniques/counters:** CTFTCTE-FOR-015

## Description

Repairs corrupt p_info headers in UPX-packed ELF binaries. Useful when the UPX magic or metadata has been zeroed to defeat automated unpacking.
