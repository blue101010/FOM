## Description

Web server scanner that checks a target against a database of known dangerous files, default
and backup files, exposed metadata and configuration artifacts, outdated server versions and
misconfigured headers or methods. Noisy and signature-based: a fast triage pass that points at
files worth fetching manually, not a proof of exploitability.
