# CTFTTOU-008 — Playwright

> **Tool ID:** `CTFTTOU-008`  
> **Related techniques/counters:** CTFTCTE-WEB-018, CTFTCTE-GAM-007, CTFTCTE-WEB-020

## Description

Browser automation and instrumentation. Subscribes before `page.goto()` to requests, responses, failures, WebSockets, console output and DOM mutations, and drives interactions (keys, clicks, movement). Capture is not limited by the page's CORS policy.
