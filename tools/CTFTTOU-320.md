# CTFTTOU-320 — SunCalc

> **Tool ID:** `CTFTTOU-320`  
> **Related techniques/counters:** CTFTCTE-OSI-004, CTFTTE-OSI-004

## Description

Web sun-position calculator: for a map point, date and time it shows solar azimuth,
elevation, sunrise/sunset lines and the shadow length for an object height. It inverts a
photo's shadows: with a known timestamp it constrains the location, and with a known
location it constrains the time. Shadows of two objects allow triangulation.
