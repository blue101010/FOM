# CTFTTOU-020 — certipy

> **Tool ID:** `CTFTTOU-020`  
> **Related techniques/counters:** CTFTTE-FPN-011, CTFTCTE-FPN-011, CTFTTE-FPN-013, CTFTCTE-FPN-013

## Description

ADCS exploitation framework. `certipy shadow` plants shadow credentials, `certipy find` enumerates vulnerable certificate templates, and `certipy req`/`certipy auth` request certificates and authenticate with them — covering ESC1 through ESC9, including the ESC4 template write. Kali ships the binary as `certipy-ad`.
