# CTFTTOU-033 — nmap

> **Tool ID:** `CTFTTOU-033`  
> **Related techniques/counters:** CTFTTE-FPN-018, CTFTCTE-FPN-018

## Description

Port scanner and service fingerprinting engine. Used to map a newly discovered domain's hosts and spot the MSSQL listener on 1433/tcp; version detection and `--defeat-rst-ratelimit` handle filtered Windows hosts.
