# CTFTTOU-321 — Shadowmap

> **Tool ID:** `CTFTTOU-321`  
> **Related techniques/counters:** CTFTCTE-OSI-004, CTFTTE-OSI-004

## Description

Web 3D sun and shadow simulator over real building and terrain models (freemium). It
renders cast shadows at any date and time, so a photo's shadow pattern can be matched on
the actual urban geometry rather than with a single azimuth line.
