# CTFTTOU-023 — openssl

> **Tool ID:** `CTFTTOU-023`  
> **Related techniques/counters:** CTFTTE-FPN-013

## Description

General-purpose cryptography toolkit. For certificate work it inspects PFX/PEM material, converts between PKCS#12 and PEM, and displays certificate fields — the companion tool for verifying what a certificate-template abuse actually enrolled.
