# CTFTTOU-046 — pickletools

> **Tool ID:** `CTFTTOU-046`  
> **Related techniques/counters:** CTFTTE-AIM-004, CTFTCTE-AIM-004

## Description

Python standard-library pickle inspection module. `pickletools.dis` disassembles a pickle stream opcode by opcode — the lightweight, dependency-free way to find the hidden call embedded in a model file.
