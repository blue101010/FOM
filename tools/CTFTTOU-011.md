# CTFTTOU-011 — name-that-hash

> **Tool ID:** `CTFTTOU-011`  
> **Related techniques/counters:** CTFTCTE-CRY-012

## Description

Identifies the hash format from a given string, returning the matching mode names and, when available, the corresponding hashcat and John the Ripper mode numbers.
