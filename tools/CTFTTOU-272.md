# CTFTTOU-272 — inql

> **Tool ID:** `CTFTTOU-272`

## Description

Burp Suite extension (standalone GUI also available) for GraphQL security testing:
schema introspection and visualization, query editor with autocompletion, and attack
surface generation. The interactive alternative to scripted dumps when crafting the
over-fetch queries against a live endpoint.
