# CTFTTOU-324 — OpenStreetMap

> **Tool ID:** `CTFTTOU-324`  
> **Related techniques/counters:** CTFTCTE-OSI-004, CTFTTE-OSI-004

## Description

Open, editable world map with detailed tagged features (roads, buildings, shops, street
furniture). Its Nominatim service geocodes and reverse-geocodes coordinates into addresses,
and its data feeds feature queries through [Overpass Turbo](CTFTTOU-325.md).

<https://www.openstreetmap.org/>
