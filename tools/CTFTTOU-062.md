# CTFTTOU-062 — garak

> **Tool ID:** `CTFTTOU-062`  
> **Related techniques/counters:** CTFTTE-AIM-002, CTFTCTE-AIM-002

## Description

NVIDIA's LLM vulnerability scanner. Runs probe plugins — prompt injection, jailbreaks, data leakage, prompt extraction — against a model or endpoint and reports which probes succeed. The fastest way to turn "the flag is behind guardrails" into a list of working payloads.
